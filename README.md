# 왜 달라졌는지 분석하고, 누구나 이해할 수 있게 설명합니다.

**금융·기업 데이터를 분석하며, 변화의 이유를 탐색하고 실행 방향을 제안하는 데이터 분석가를 지향합니다.**

예측값을 제시하는 데서 더 나아가 **어떤 요인이 결과와 연결되는지, 무엇을 더 확인해야 하는지**를 살펴봅니다. 분석을 처음 접하는 사람도 문제부터 결과까지 따라올 수 있도록, 과정은 명료하게 정리하고 결과는 쉬운 말로 설명합니다.

`금융·기업 데이터` · `통계적 검증` · `설명 가능한 분석` · `의사결정 지원`

## 대표 프로젝트

### 01 · 어느 시장의 어떤 고객부터 만나야 할까?
**시장기회 발굴과 RM 상담 우선순위 · Final**

외부 시장 규모와 내부 거래를 비교해 **후보시장 19개·연결 법인 352개**를 좁혔습니다. 경기 제조업의 관계 약화 경보 17개 법인을 중심으로 상담 방향과 비용·손익분기 조건을 검토했습니다.

**시장 비교 → 거래 변화 확인 → 고객 우선순위 → 영업 경제성 시나리오**

`Python` `Random Forest` `SHAP` `시나리오 분석` `웹 대시보드`

### 02 · 거래가 활발한 고객과 수익성이 높은 고객은 같을까?
**[고객 가치 세분화 · Statistics ↗](https://github.com/dlllll0/IMBK8_Corporate_Customer_Value_Segmentation-Statistics)**

활동성과 추정 수익성을 별도 지수로 설계하고, 통계 검정으로 고객군의 차이를 살폈습니다. 기존 등급 안에서도 거래 특성이 다른 집단을 구분해 **고객군별 관리·상품 이용 점검 방향**을 제안했습니다.

**지표 설계 → 고객 세분화 → 통계 검정 → 고객군별 해석**

`Python` `pandas` `SciPy` `비모수 검정` `지표 설계`

### 03 · 대구·경북의 우수 거래 패턴을 다른 지역에서도 찾을 수 있을까?
**지역 확장 기회 분석 · ML**

추정 예대마진과 관련된 변수를 회귀 모델로 살펴보고, 두 차례 군집화로 기준집단과 타지역 비교군을 구성했습니다. 지역별 패턴을 비교해 **부산·경남·울산**을 후속 검토 후보로 찾고, 거래 특성에 따른 캠페인 방향을 제안했습니다.

**회귀·변수 선정 → 대구·경북 기준군 → 타지역 비교군 → 지역 유사도**

`Random Forest` `K-Means` `코사인 유사도` `지역 비교`

## 제가 분석하는 방식

**질문을 구체화하고 → 데이터를 검증하고 → 차이를 설명하고 → 행동으로 연결합니다.**

- **왜 이 분석을 하는가:** 의사결정에 필요한 질문을 먼저 정하고 방법을 선택합니다.
- **무엇이 차이를 만드는가:** 집단·변수·기간을 비교해 원인 후보를 탐색하고, 관측된 관계와 검증된 인과효과를 구분합니다.
- **어떻게 이해를 도울 것인가:** 단계마다 목적과 결과를 연결하고, 그래프와 쉬운 설명으로 판단 근거를 전달합니다.
- **그래서 무엇을 할 것인가:** 실행 대상·비용·가정·추가 검증 방법을 함께 제시합니다.
